11)Przepisz linie kody pod nimi wytłumaczenie jak działa ta ten fragment kodu
window.open("obraz.html","okienko","toolbar=no,directories=no,menubar=no,height=280,width=160,top=200,left=200");
.........................otwiera nowe okno z plikiem obraz.html o podanych wymiarach i pozycji.......................
toolbar=no → ukrywa pasek narzędzi
directories=no, → ukrywa pasek zakłódek
menubar=no, → ukrywa menu górne
height=280, → wysokość okna 280px
width=160, → szerokość okna 160px
top=200, → pozycja od góry 200px
left=200 → pozycja od lewej 200px
