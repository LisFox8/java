JavaScript – pytania teoretyczne

1. Wymień cztery sposoby wyprowadzania danych w JS.

Odpowiedź:

  1. console.log() – wyświetla dane w konsoli.
  2. alert() – wyświetla komunikat w oknie.
  3. document.write() – wyświetla dane na stronie.
  4. innerHTML – wyświetla dane w elemencie HTML.

2. Czym jest funkcja w JS? Omów przy użyciu 4 podpunktów.

Odpowiedź:

  1. Funkcja – fragment kodu wykonujący określone zadanie.
  2. Nazwa – pozwala wywołać funkcję.
  3. Parametry – dane przekazywane do funkcji.
  4. return – zwraca wynik działania funkcji.

3. Omów metody getElementsByName, getElementById, getElementsByTagName.

Odpowiedź:

Metoda Opis
getElementsByName() Wyszukuje elementy posiadające określony atrybut name.
getElementById() Wyszukuje element posiadający określone id.
getElementsByTagName() Wyszukuje elementy według nazwy znacznika, np. p lub div.

4. Omów właściwości innerHTML, innerText, className.

Odpowiedź:

innerHTML – pozwala odczytać lub zmienić zawartość HTML elementu.

innerText – pozwala odczytać lub zmienić tekst elementu.

className – pozwala odczytać lub zmienić nazwę klasy CSS elementu.
